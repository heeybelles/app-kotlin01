# 📱 Atividade de Kotlin — Android Studio

Este repositório contém uma série de aplicações desenvolvidas em **Kotlin** utilizando o **Android Studio** para fins acadêmicos.

---

## 🚀 Aplicativos Incluídos

* **🧮 Cálculos Básicos:** Aplicação simples para execução de operações matemáticas fundamentais.
* **🌡️ Conversor de Temperatura:** Conversão dinâmica de graus Celsius (°C) para Fahrenheit (°F).
* **⚡ Lei de Ohm:** Calculadora dedicada à Primeira Lei de Ohm ($V = I \cdot R$).

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Kotlin
* **IDE:** Android Studio
